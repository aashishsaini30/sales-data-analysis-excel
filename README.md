# Excel Sales Analysis

## Project Overview
This project analyzes sales data using Microsoft Excel to summarize sales performance, profit, order quantity, and category-wise results.

## Tools Used
- Microsoft Excel
- Excel Formulas and Functions
- Lookup Functions
- PivotTables
- Charts and Data Validation

## Project Work
- Organized and reviewed sales data.
- Used formulas such as IF, SUMIF, and COUNTIF.
- Applied lookup functions for data retrieval.
- Created PivotTables and charts for category and regional analysis.
- Prepared a sales summary and dashboard.

## Key Metrics
- **Total Sales:** ₹2,41,097.66
- **Total Profit:** ₹18,733.27
- **Total Orders:** 479
- **Total Quantity:** 3,797
- **Average Order Value:** ₹503.34
